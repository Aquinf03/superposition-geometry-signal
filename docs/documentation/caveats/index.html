Reading the signal

Geometry beside loss is a live training signal. These notes make the dashboard sharper. Detail: root failure_notes.md.

When the curve is quiet

SituationWhat you see
Wrong / inactive layerCurves barely twitch while loss falls.
Coarse cadenceSparse points look constant.
Tiny / saturated bankMetrics stuck near floor or ceiling.
Already-collapsed regimeLate spectral ≈ 0 and stays there.

Widen layers, probes, or step budget, then re-run python experiments/validate_training_geometry.py --run-dir ….

How the signal moves

  • Corpus scale. Short fine-tunes pack hard; geometry tracks that trajectory. Scale data for scale claims.
  • Late-layer collapse. Cross-feature gaps shrink after spectral collapse. Read structure at mid layers; treat late collapse as a phase marker.
  • Bank relative. Location probes make location features look coherent. Freeze probes in the sidecar.
  • Control. Train-bank movement and held-out checks both matter. Run validate_control_geometry.py.
  • Edits. Edit-time nudges move geometry when weights change; use them alongside the training loop, not instead of it.

Standard read of a run

  1. Loss + multi-layer plot first.
  2. Note which layer phase moved (collapse vs mild drift).
  3. Diff selected features at mid layers.
  4. Run training validate; if control is on, run control validate + held-out claims.

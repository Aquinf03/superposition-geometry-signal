CLI reference

Binary: spg (also python -m spg). After install, run spg --help.

Prerequisitepip install -e . from the repo root

spg track

Fine-tune with live loss | geometry. Optional soft control when the YAML has control.enabled: true.

FlagDescription
-c, --configTrain YAML under experiments/configs/.
example
$spg track --config experiments/configs/train_gpt2_small_geometry.yaml
$spg track --config experiments/configs/train_gpt2_small_geometry_control.yaml
$spg track --config experiments/configs/train_gpt2_small_geometry_control_band.yaml

spg diff

Default: checkpoint A vs B geometry. With --features: cross-feature A vs B at one checkpoint.

FlagDescription
-c, --configTrain / diff YAML.
--run-dirOverride results run directory.
--featuresCross-feature mode instead of ckpt A vs B.
--step-a / --step-bCheckpoint steps (default mode).
--stepCheckpoint step for --features.
--pair A BFeature pair for --features (repeatable).
--deviceDevice override.
--no-plotsSkip PNG writes.
example
$spg diff --config experiments/configs/train_gpt2_small_geometry.yaml
$spg diff --features --config experiments/configs/train_gpt2_small_geometry.yaml

spg plot

Plot loss + geometry curves from signals.csv.

FlagDescription
csvPath to signals.csv (optional positional).
-o, --outOutput PNG path.
example
$spg plot experiments/results/train_gpt2_small_geometry/signals.csv

spg view

Interactive HTML neighborhood scrubber for a run directory.

FlagDescription
--run-dirRun dir with signals.csv (+ optional diffs).
-o, --outOutput HTML (default <run-dir>/neighborhood.html).
--openOpen in the default browser.
example
$spg view --run-dir experiments/results/train_gpt2_small_geometry --open

spg demo

Toy GeoControl: point target, band, and feature-relative (no model). Alias: spg control-demo.

example
$spg demo

spg edit-demo

Edit-time geo nudge on one MLP W_out.

FlagDescription
-c, --configEdit YAML (default edit_geo_nudge.yaml).
example
$spg edit-demo

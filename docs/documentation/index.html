Getting started

spg treats superposition geometry like loss: a live signal you print every step, diff for selected features, plot beside the loss curve, and optionally steer with a soft regularizer.

How the pieces fit

NameWhat it is
spgPython package + CLI (pip install -e .).
TrackerLogs step / loss / geometry_* to signals.csv and prints a live line.
DiffCompare feature neighborhoods across steps or pairs.
GeoControlOpt-in soft regularizer on one layer + metric toward a target or band.
spg trackHero fine-tune loop with live geometry (and optional control).

SDK (few lines)

shell 
$pip install -e .
python 
from spg import Tracker, Diff, plot
import torch

t = Tracker(results_dir="runs", run_name="quickstart", live_print=True)
q0, q1 = torch.randn(32), torch.randn(32)
bank = torch.randn(64, 32)
for step, (loss, q) in enumerate([(1.2, q0), (0.8, q1)]):
    snap = Diff.snapshot(q, bank, feature_id="demo", step=step)
    t.log(step=step, loss=loss, geometry=snap["metrics"])
d = Diff.compare(
    Diff.snapshot(q0, bank, feature_id="t0"),
    Diff.snapshot(q1, bank, feature_id="t1"),
)
print("Δ summary", round(d["summary_score"], 4))
plot(t.csv_path)

That is the loop: Tracker logs live loss | geometry, Diff compares neighborhoods, plot draws the curves. Soft control is opt-in via GeoControl (see Control).

CLI

shell 
$spg demo
$spg plot experiments/results/train_gpt2_small_geometry/signals.csv
$spg view --run-dir experiments/results/train_gpt2_small_geometry --open
$spg track --config experiments/configs/train_gpt2_small_geometry.yaml
$spg track --config experiments/configs/train_gpt2_small_geometry_control.yaml

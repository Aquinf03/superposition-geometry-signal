Control

Loss has a knob. Geometry gets one too: push packing toward a target while you train. Control is off by default.

Modes

ModeMechanismUse
pointλ · (metric − target)²Aim L8 interference at 0.35
bandHinge outside [lo, hi]Stabilize packing while fine-tuning
feature-relativeShrink related Δ, keep unrelated above a marginStructure the tangle, not just scalars

GeoControl API

Start with one layer, one metric, one λ. Warmup logs geometry with λ=0, then arms the regularizer.

python
from spg import GeoControl, FeatureRelativeControl, format_control_line

control = GeoControl(
    layer=8, metric="interference_mean",
    target=0.35, weight=1e-2, enabled=True,
)
band = GeoControl(
    layer=8, metric="interference_mean",
    mode="band", lo=0.30, hi=0.40,
    weight=1e-2, enabled=True,
)
# loss = lm_loss + control.penalty_on_value(metric_t)

Validate out-of-metric

Validate control out-of-metric: downstream loss healthy, related ≪ unrelated preserved, held-out probes clean. See experiments/results/control_vs_baseline_seed0/ and paper/figures/table05_validation.md.

Rails

  • Always log loss and geometry live; control must not hide the watch dashboard.
  • Freeze probe bank + layers in the run config.
  • Warmup before arming; abort if the signal is flat.
  • Train-bank movement ≠ held-out geometry. Read held-out claims before celebrating.

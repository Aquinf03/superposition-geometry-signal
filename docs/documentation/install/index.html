Install

spg is a normal Python package at sdk/spg/. Editable install puts the spg CLI on your PATH.

PrerequisitePython ≥ 3.10 · pip · PyTorch

venv + install

From the repo root. requirements.txt covers train deps; pip install -e . installs the SDK and CLI.

example
$python -m venv .venv
$source .venv/bin/activate
$pip install -r requirements.txt
$pip install -e .
$python scripts/tests/check_env.py
$spg --help

Optional: TransformerLens / HF

Hero train / view on GPT-2 need TransformerLens and transformers. Install the full extra if you skipped them:

example
$pip install -e ".[full]"

Live line color

TTY live lines use a small ANSI palette (teal geometry, rose control). Off with NO_COLOR or SPG_COLOR=0; force on with SPG_COLOR=1.

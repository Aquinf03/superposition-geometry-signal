Metrics

Logged every step beside loss as geometry_* columns in signals.csv. Live stdout shortens names (interference, spectral, coact).

interference_mean

Mean absolute cosine similarity between the query and its top-k neighbors in the probe bank. High means the query sits near many other directions.

spectral_participation

How the query's energy spreads across eigenvectors of the neighbor covariance, normalized to [0, 1]. Near 0 is localized; near 1 is more superposition-like.

coactivation_overlap

Average Jaccard overlap of top-activated coordinates between query and each neighbor (capped to roughly d/4 dims so dense vectors cannot trivially score 1).

Multi-layer track

Hero configs set geometry.layers: [4, 8, 11]. CSV columns look like geometry_L8_interference_mean. Checkpoints freeze a geometry sidecar next to every weight save so diffs reuse the same probes.

Diff

Checkpoint diffs and cross-feature diffs live under the run dir (diff_ckpt_*, diff_features_step_*). Related location pairs should score closer than unrelated pairs at mid layers. Prefer mid layers after late-layer spectral collapse.
